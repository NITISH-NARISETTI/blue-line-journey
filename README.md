# horizontal scroll portfolio

Create a wide panoramic editorial portfolio “About Me” timeline for a young Indian graphic and visual communication designer.

The composition is designed specifically for a HORIZONTAL SCROLL website, like a long visual journey from left to right. It should feel like an experimental independent design magazine spread rather than a conventional resume or corporate portfolio.

CORE CONCEPT:

A dotted electric-blue line travels continuously through the entire composition, acting as the timeline and visual spine. The line should feel hand-drawn and slightly imperfect, with organic curves, loops, sudden dips and rises. Imagine the line being drawn live as the viewer scrolls horizontally. Important moments should cause the line to change behaviour
